# VideoOS P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a locally runnable, CLI-first VideoOS P0 vertical slice that analyzes media, produces an explainable versioned timeline, renders a new video through safe FFmpeg argv, and emits machine-readable QA evidence.

**Architecture:** Use one installable Python package under `src/videoos/` with small core, analysis, speech, captions, profiles, planner, renderer, QA, and CLI modules. Keep FFmpeg/ffprobe behind subprocess and adapter boundaries; make optional speech and scene capabilities observable and non-fatal while keeping the deterministic trim/reframe/audio path working without paid services.

**Tech Stack:** Python 3.12+, Pydantic v2, Typer, Rich, PyYAML, FFmpeg/ffprobe, pytest, Ruff, and optional faster-whisper/PySceneDetect adapters. No web service, database, paid API, or GUI is required for this milestone.

**Spec:** `docs/superpowers/specs/2026-09-06-videoos-p0-design.md`

## Global Constraints

- Python 3.12+ is the minimum supported runtime.
- The default experience must not require paid APIs or upload source media.
- Original media is never modified; renders and metadata are separate outputs.
- All FFmpeg and ffprobe calls use subprocess argument arrays with `shell=False`.
- User-controlled paths, filenames, subtitle text, and manifest values are treated as untrusted.
- `timeline.json` contains structured decisions, never arbitrary AI prose or generated shell commands.
- Schema version `1` is explicit; unsupported future versions fail with a useful error.
- Optional providers degrade to a documented warning and deterministic fallback; required FFmpeg/ffprobe failures are non-zero errors.
- Analysis is keyed by source SHA-256 plus analysis configuration/tool fingerprint.
- Every automatic decision records a reason and confidence when a meaningful confidence exists.
- Tests use tiny synthetic media and never download large fixtures.
- Work only on `feat/videoos-universal-editor`; do not merge or deploy.
- Each task ends with a focused test run and a coherent commit.
