# Rendering

The P0 renderer is local FFmpeg. It compiles validated structured timelines into argument arrays and never invokes a shell. Default outputs stay in the project `renders/` directory. An explicit `render --output PATH` may select a location outside the project: explicit `--output` paths use their own validated parent directory and are not constrained to the project directory. In either case, the output must not be an input source, an existing destination is rejected, and staging plus atomic publication are constrained to that selected destination parent.

Use `videoos render PROJECT_JSON --dry-run` after structured edits, then render and run `videoos qa OUTPUT --timeline timeline.json`. A dry run is plan validation, not a media render. Missing `ffmpeg` blocks actual rendering; missing `ffprobe` blocks source/output verification. Local integration tests exercise installed FFmpeg/ffprobe but do not establish CI or deployed/live behavior.

P0 supports one continuous video track with embedded source audio. Unsupported gaps, overlaps, multiple tracks, standalone audio tracks, and empty segments fail before FFmpeg. Audio presence comes from verified source metadata; omitting adjustments preserves audio. Mixed sources get silence where audio is absent. Adjustments run in this order: per-segment LUFS normalization, gain, fades, then common 48 kHz stereo format/padding. Gain/fades intentionally affect the final level after normalization. Fades cannot exceed segment duration. Timing-preserving crop/scale zoom retains frame timestamps, and `setsar=1` establishes square output pixels.

Validated caption cues are serialized as managed UTF-8 ASS. Rendering captions requires FFmpeg's `subtitles` filter (libass); missing capability produces an explicit nonzero error, including on dry runs. Text remains outside filter expressions. ASS control punctuation (backslash and braces) is displayed as fullwidth punctuation to prevent style/drawing overrides; intentional line breaks are serializer-owned. Font/glyph availability and native burn-in remain dependent on the installed FFmpeg/font environment.

QA scans decoded video with `blackdetect` and audio with `volumedetect`. Missing filters, failed scans, absent audio, and unknown source expectations are reported as unavailable warnings, never measurement passes. Black endpoint detections and advisory peaks are warnings; missing required streams, wrong duration/dimensions/display ratio, and invalid timeline bounds fail. Every successful media-producing CLI command persists QA; a failed container probe also persists a failed report.

Local command execution defaults to 3600 seconds and 16 MiB captured output per stream, with a 128 KiB argument limit. Configure `VIDEOOS_COMMAND_TIMEOUT_SECONDS` and `VIDEOOS_COMMAND_MAX_OUTPUT_BYTES` for longer jobs. Exceeding a limit terminates the process group and raises a typed error; measurement failures become unavailable evidence rather than truncated successes. These limits cover external local processes, not in-process optional Whisper inference.
